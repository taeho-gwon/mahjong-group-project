# ADR: 역할별 권한 정비

- **날짜**: 2026-03-03
- **상태**: 승인됨

## 배경

기존 RBAC에 불일치와 누락이 발견됨:
- 이벤트 생성 시 그룹 멤버십 미검증 (비멤버도 생성 가능)
- GET /groups/{id}가 비인증자에게 멤버 목록 노출
- 이벤트 수정/삭제가 생성자에게만 제한되어 Owner/Admin이 관리 불가

## 결정

### 1. 그룹 상세 조회 (GET /groups/{id})
- **Public 그룹**: 인증 유저만 조회 가능
- **Private 그룹**: 그룹 멤버만 조회 가능
- 비인증 사용자는 그룹 목록(GET /groups)에서 기본 정보만 확인

### 2. 이벤트 생성 (POST /events)
- **Owner/Admin만** 생성 가능
- 그룹 멤버십 + 역할 체크 추가
- 일반 멤버는 이벤트 없이 기록 생성 (일반 경기로 그룹 랭킹 반영)

### 3. 이벤트 수정/삭제 (PUT/DELETE /events/{id})
- **Owner/Admin** 모두 가능 (기존: 생성자만)
- Owner가 Admin이 만든 이벤트도 관리 가능

### 4. 기록 수정/삭제 (PUT/DELETE /game-records/{id})
- **Owner/Admin만** (현재 유지, 변경 없음)
- 기록 생성자 본인도 수정 불가 — 기록 무결성 보장

## 영향

- BE: 서비스 레이어 권한 로직 수정 (event, group)
- FE: 이벤트 생성 버튼 Owner/Admin에게만 표시, 비인증 그룹 상세 차단
- 테스트: 권한 시나리오 테스트 추가
