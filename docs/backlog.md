### ID 규칙
- 상위 작업: `1`, `2`, `3` ...
- 서브태스크: `1.1`, `1.2`, `1.3` ...
- 상위 작업 완료 시 서브태스크 전부 삭제

### Status 값
- `pending`: 작업 대기
- `in-progress`: 진행 중
- `blocked`: 선행 작업 대기 (Depends 참조)
- `done`: 서브태스크 완료 (상위 작업 완료 시 일괄 삭제)
